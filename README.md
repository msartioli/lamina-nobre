# Lâmina Nobre

Site demonstrativo de uma barbearia premium, criado para portfólio da Artioli Digital.

## Stack

- React
- Vite
- Tailwind CSS

## Scripts

- `npm run dev`: ambiente de desenvolvimento
- `npm run build`: build de produção
- `npm run preview`: preview local da build

- Domínio futuro: `laminanobre.artiolidigital.com.br`
